# Space Mission Launch Analysis

## Overview
A beginner data analysis project exploring historical space mission launches using Python, Pandas, and Matplotlib.

## Objectives
- Analyse launch trends over time.
- Compare mission outcomes.
- Identify leading organisations and launch locations.
- Explore recorded launch costs and success rates.

## Tools
Python • Pandas • Matplotlib • Jupyter Notebook

## Dataset
4,324 space mission records from [Kaggle](https://www.kaggle.com/datasets/sefercanapaydn/mission-launches/data).

## Key Findings
- **Most launches:** RVSN USSR
- **Most-used launch location:** Site 31/6, Baikonur Cosmodrome
- **Highest average recorded price:** NASA
- Successful missions had a higher average recorded price than failed missions in the available data.

## Limitations
Many launch prices are missing, their units need confirmation, and 2020 data covers only part of the year.
